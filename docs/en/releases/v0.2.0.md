# LLM2Jev v0.2.0

**Ground image targets with `Box`, alongside structured decisions from text and images.**

## Highlights

- **Image grounding with `Box`:** locate a described target and return a normalized bounding box with coordinate-token confidence.
- **Mixed questions:** combine `Box` with `Choice`, `Score`, and `Noul` in one request.
- **Prompt-rendering refactor:** one request renderer now handles every question type, while scoring and Box generation keep their distinct backend paths.
- **Backend generation support:** SGLang, Transformers, and MLX expose generated token text and probabilities for Box responses.
- **Prefill scoring remains unchanged:** `Choice`, `Score`, and `Noul` continue to read yes/no scores without answer generation.

## Compatibility

Box requires an image-capable model and backend configuration. The current prompt expects one JSON bounding box using integer coordinates normalized to 0–1000. Returned edges are fractions in `[0, 1]`. See the [multimodal guide](../multimodal.md#box-locate-a-target-in-an-image) for request examples, supported output forms, and limitations.

Box has no built-in “not found” result. When the target may be absent, include a `Noul` question and apply an application-specific threshold before using the box. The reported confidence measures certainty in generated coordinate tokens; it is not calibrated localization accuracy.
