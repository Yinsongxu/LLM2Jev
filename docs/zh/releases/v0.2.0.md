# LLM2Jev v0.2.0

**使用 `Box` 定位图片目标，并在同一请求中完成结构化决策。**

## 主要更新

- **`Box` 图片目标定位：** 根据描述定位目标，返回归一化边界框及坐标 token 置信度。
- **混合题型：** 同一请求可组合 `Box`、`Choice`、`Score` 和 `Noul`。
- **提示词渲染重构：** 由同一请求 renderer 处理所有题型，同时保留评分与 Box 坐标生成各自的 backend 流程。
- **Backend 生成能力：** SGLang、Transformers 和 MLX 提供 Box 输出所需的生成 token 文本与概率。
- **评分流程保持 prefill：** `Choice`、`Score` 和 `Noul` 仍通过 yes/no 分数完成判断，不生成答案。

## 兼容性与限制

使用 Box 需要支持图片输入的模型和 backend 配置。当前提示词要求模型返回一个 JSON 边界框，坐标为 0–1000 的整数；结果中的边界值会转换为 `[0, 1]` 范围内的比例。请求示例、支持的输出格式和限制见[多模态指南](../multimodal.md#box定位图片中的目标)。

Box 没有内置的“未找到”结果。目标可能不存在时，请同时提交 `Noul` 问题，并由应用设定阈值后再使用边界框。置信度衡量生成坐标 token 时模型的确定程度，不代表经过校准的定位准确率。

LLM2Jev 是独立开源项目，与 Jev 或 TypeSafe 没有关联，也未获得其认可或授权。
